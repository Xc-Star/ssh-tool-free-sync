本次更新带来 AI Agent 助手：在终端右侧打开对话面板，配置你自己的 API，让 AI 直接操控远程 SSH 会话——查日志、排查问题、改配置，描述任务即可。每条命令执行前都会请求你的确认，全程可控。

This release brings an AI Agent assistant: open the chat panel next to your terminal, plug in your own API, and let the AI drive the remote SSH session — inspect logs, troubleshoot, edit configs, just by describing the task. Every command asks for your approval first.

### 更新内容 · What's new

- **新增 AI 对话面板**：点击终端工具栏的机器人图标（或命令面板搜「AI 助手」）打开右侧聊天面板，自动绑定当前 SSH 会话；AI 回复流式渲染、可随时停止，还可一键附带最近的终端输出作为上下文。
  **AI chat panel**: open it from the terminal toolbar (or the command palette); it binds to the current SSH session, streams replies, can be stopped at any time, and can attach recent terminal output as context.
- **自带 API，多供应商预设**：支持 OpenAI、Claude、Gemini、DeepSeek、通义千问、智谱 GLM、MiniMax、Ollama（本地）以及 OpenAI 兼容 / Anthropic 兼容 / 自定义网关，预设自动填好地址与认证方式（裸域名自动补全 /v1）；可保存多套命名配置一键切换，模型列表自动发现、一键测试连接。API Key 使用系统钥匙串加密存储在本设备，AI 请求由应用直连服务商，不经过任何第三方。
  **Bring your own API**: presets for OpenAI, Claude, Gemini, DeepSeek, Qwen, Zhipu GLM, MiniMax, Ollama (local) plus OpenAI-compatible / Anthropic-compatible / custom gateways — presets prefill the URL and auth (a bare domain gets /v1 appended automatically). Keep multiple named configs, discover models automatically and test the connection in one click. API keys are encrypted with the OS keychain on your device; requests go straight from the app to the provider.
- **两种命令执行方式**：AI 默认通过独立通道在远程主机上执行命令（run_command），精确获取输出与退出码，不打扰你正在使用的交互终端；sudo 密码、vim 等 TTY 场景会请求向终端直接输入（send_keys），此类操作始终需要单独确认。
  **Two execution modes**: by default the AI runs commands through a separate exec channel on the remote host (precise output and exit codes) without touching your interactive terminal; for TTY-only situations (sudo prompts, editors) it can ask to type directly into your terminal (send_keys) — always with explicit approval.
- **安全确认机制**：每条命令执行前弹出「批准 / 拒绝」，5 分钟未响应视为拒绝；可选择「本次会话自动执行」，也可在设置中开启全局自动模式；最大轮次与命令超时时间均可配置。注意：Agent 模式需要选择支持工具调用（function calling）的模型，部分网关的逆向代理模型不支持。
  **Safety approvals**: every command shows an approve / decline prompt (no answer within 5 minutes counts as declined); "auto-run for this chat" and a global auto mode are available, and max turns / command timeout are configurable. Note: agent mode requires a model with function-calling support — some reverse-proxy models on gateways do not support it.

### 首次运行 · First launch

- **Windows**：安装包未签名，SmartScreen 拦截时点击「更多信息 → 仍要运行」。
  The installer is unsigned: if SmartScreen blocks it, click **More info → Run anyway**.
- **macOS**：应用未经 Apple 公证，首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」。
  The app is not notarized by Apple: if macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux**：Ubuntu / Debian 推荐安装 deb；AppImage 需要 FUSE 2（Ubuntu 24.04：`sudo apt install libfuse2t64`）。
  On Ubuntu / Debian the `.deb` is recommended; the AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
