本次更新让 AI 助手的「停止」真正停下来：点停止不仅中断对话，还会向远程主机上正在执行的命令发送中断信号（SIGINT），不会留下还在跑的进程。同时新增「思考过程」显示，支持 DeepSeek、Claude、Gemini 等推理模型的思维链流式展示。另外 README 全面更新了 AI 助手的介绍与截图。

This update makes the AI assistant's "Stop" button actually stop: beyond ending the conversation it now sends an interrupt signal (SIGINT) to the command running on the remote host, so nothing keeps running in the background. It also adds a collapsible "reasoning" view that streams the thinking of reasoning models such as DeepSeek, Claude and Gemini. The README now includes a full AI assistant introduction with new screenshots.

### 更新内容 · What's new

- **停止即中断**：停止 AI 任务时，正在远程执行的命令会收到 SIGINT 中断信号（超时中断同样处理），向终端输入（send_keys）的捕获也会立即结束——不再留下后台继续运行的进程。
  **Stop really stops**: stopping an AI task now interrupts the command running on the remote host with SIGINT (timeouts behave the same), and terminal-input capture ends immediately — no orphaned processes keep running.
- **新增思考过程显示**：推理模型（DeepSeek R1 风格思维链、Claude 扩展思考、Gemini 思考签名）的思考内容会实时流式显示在回复上方的可折叠区块中；多轮对话时自动回传给产生它的模型与端点，兼容要求带回历史的深度思考 API。
  **Reasoning view**: the thinking of reasoning models (DeepSeek-style chain of thought, Claude extended thinking, Gemini thought signatures) streams live in a collapsible block above the reply; during multi-turn runs it is replayed only to the endpoint and model that produced it, staying compatible with thinking APIs that require it in history.
- **命令状态更清晰**：命令卡片区分「已完成 / 已拒绝 / 已中止 / 执行出错」四种结束状态。
  **Clearer command states**: command cards now distinguish finished / declined / aborted / failed.
- **文档与截图**：README（中英双语）新增「AI 助手」章节与功能表条目，收录 AI 对话面板与 AI 设置两张新截图，并说明 Agent 模式需要支持工具调用（function calling）的模型。
  **Docs & screenshots**: the bilingual README gains an AI assistant section, feature-table entry and two new screenshots (chat panel and settings), noting that agent mode requires a model with function-calling support.

### 首次运行 · First launch

- **Windows**：安装包未签名，SmartScreen 拦截时点击「更多信息 → 仍要运行」。
  The installer is unsigned: if SmartScreen blocks it, click **More info → Run anyway**.
- **macOS**：应用未经 Apple 公证，首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」。
  The app is not notarized by Apple: if macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux**：Ubuntu / Debian 推荐安装 deb；AppImage 需要 FUSE 2（Ubuntu 24.04：`sudo apt install libfuse2t64`）。
