本次更新新增 WebDAV 同步与本地终端快速跳转，并修复了 macOS 关闭报错和关闭标签跳转到 SFTP 的问题。

This release adds WebDAV sync and quick local-terminal access, and fixes a macOS quit error and the issue where closing a tab jumped to SFTP.

### 更新内容 · What's new

- **新增 WebDAV 同步**：多设备同步新增 WebDAV 存储，可用于 Nextcloud、ownCloud、群晖 DiskStation 或任意兼容 WebDAV 的服务器，无需数据库、无需部署服务端程序；保险库以单个 JSON 文件保存，通过 ETag 条件请求做乐观并发控制，多设备同时写入不会互相覆盖。
  **New WebDAV sync**: multi-device sync now supports WebDAV storage — Nextcloud, ownCloud, Synology DiskStation, or any WebDAV-compatible server — with no database and no server-side app required. The vault is stored as a single JSON file and all updates use ETag conditional requests for optimistic concurrency, so concurrent writes from multiple devices never overwrite each other.
- **新增本地终端快速跳转**：新增快速打开本地终端的入口，一键即可在当前窗口打开本地 Shell（PowerShell / pwsh / cmd / WSL / Git Bash / zsh / bash…）。
  **Quick local terminal**: a new shortcut to open a local shell (PowerShell / pwsh / cmd / WSL / Git Bash / zsh / bash…) in the current window with a single click.
- **修复 macOS 关闭报错**：修复在 macOS 上退出应用时出现的报错。
  **Fixed a macOS quit error**: resolved an error thrown when quitting the app on macOS.
- **修复关闭标签跳转到 SFTP**：修复关闭终端标签页后界面错误跳转到 SFTP 的问题。
  **Fixed closing a tab jumping to SFTP**: closing a terminal tab no longer jumps the view to SFTP.

### 首次运行 · First launch

- **Windows**：安装包未签名，SmartScreen 拦截时点击「更多信息 → 仍要运行」。
  The installer is unsigned: if SmartScreen blocks it, click **More info → Run anyway**.
- **macOS**：应用未经 Apple 公证，首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」。
  The app is not notarized by Apple: if macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux**：Ubuntu / Debian 推荐安装 deb；AppImage 需要 FUSE 2（Ubuntu 24.04：`sudo apt install libfuse2t64`）。
  On Ubuntu / Debian the `.deb` is recommended; the AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
