本次更新修复了 WebDAV 同步对坚果云等服务商的兼容问题。这类服务不允许在 WebDAV 根目录直接创建文件，此前会导致「测试连接」直接失败；现在会自动在根目录下创建 `ssh-tool` 子目录并把同步文件放进去，粘贴服务商给出的根地址即可使用。

This release fixes WebDAV sync with providers such as Jianguo Cloud, which refuse to create files directly in the WebDAV root — previously that made the connection test fail outright. SSH Tool now creates an `ssh-tool` subfolder automatically and keeps the sync file there, so the root URL from your provider just works.

### 更新内容 · What's new

- **兼容坚果云等根目录不可写的服务**：写入被服务器拒绝（HTTP 404）时，自动创建 `ssh-tool` 子目录并重试，无需手动建目录；已经在旧位置同步过的用户路径保持不变，不会移动或丢失数据。
  **Works with root-only providers**: when a write is refused (HTTP 404) SSH Tool creates an `ssh-tool` subfolder and retries, so no manual setup is needed; existing setups keep their current location and nothing is moved.
- **修复父目录缺失时的误判**：部分服务对「父目录不存在」返回 409 而不是 404，此前会被当成连接错误；现在正确识别为「文件还不存在」。
  **Fixed a false error on missing parents**: some servers answer 409 (not 404) when an ancestor folder is missing; this is now treated as "no file yet" instead of an error.
- **错误提示更准确**：写入被服务器拒绝时，提示会说明是服务商限制，而不是笼统的「目录不存在」。
  **Clearer errors**: a refused write now says the provider rejected it, instead of a generic "folder not found".
- **读取不走缓存**：读取同步文件时携带 `Cache-Control: no-cache`，避免中间缓存导致刚写入的内容读回旧值。
  **Reads bypass caches**: reading the sync file now sends `Cache-Control: no-cache`, so a stale proxy cannot return an outdated copy right after a write.
- **文档**：README（中英双语）与应用内 WebDAV 帮助补充坚果云说明，含「请使用应用专用密码而非登录密码」的提示。
  **Docs**: the bilingual README and the in-app WebDAV help now cover Jianguo Cloud, including the app-password requirement.

### 首次运行 · First launch

- **Windows**：安装包未签名，SmartScreen 拦截时点击「更多信息 → 仍要运行」。
  The installer is unsigned: if SmartScreen blocks it, click **More info → Run anyway**.
- **macOS**：应用未经 Apple 公证，首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」。
  The app is not notarized by Apple: if macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway**.
