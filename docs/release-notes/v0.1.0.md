首个公开版本。跨平台 SSH 客户端，功能对标 Termius；多设备同步免费，数据存进你自己的 PostgreSQL、MySQL / MariaDB 或 Cloudflare D1，主密码端到端加密，数据库里只有密文。

The first public release: a cross-platform SSH client that matches Termius feature-for-feature, with free multi-device sync through your own PostgreSQL, MySQL / MariaDB or Cloudflare D1 — end-to-end encrypted with your master password, so the database only sees ciphertext.

### 首次运行 · First launch

- **Windows**：安装包未签名，SmartScreen 拦截时点击「更多信息 → 仍要运行」。
  The installer is unsigned: if SmartScreen blocks it, click **More info → Run anyway**.
- **macOS**：应用未经 Apple 公证，首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」。
  The app is not notarized by Apple: if macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux**：Ubuntu / Debian 推荐安装 deb；AppImage 需要 FUSE 2（Ubuntu 24.04：`sudo apt install libfuse2t64`）。
  On Ubuntu / Debian the `.deb` is recommended; the AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).

### 主要功能 · Highlights

- 主机分组与标签、快速连接、跳板机与代理、SSH Agent、密码 / 私钥 / 二次验证登录
  Hosts with groups and tags, quick connect, jump hosts and proxies, SSH agent, password / key / 2FA login
- 多标签与分屏终端、广播输入、命令自动补全；本地终端、Telnet、串口
  Tabs and split-pane terminals, broadcast input, autocomplete; local terminal, Telnet, serial
- 双栏 SFTP 与传输队列、端口转发（本地 / 远程 / SOCKS）、代码片段、密钥库、已知主机
  Dual-pane SFTP with a transfer queue, port forwarding (local / remote / SOCKS), snippets, keychain, known hosts
- 自托管同步：PostgreSQL（实时）、MySQL / MariaDB、Cloudflare D1，端到端加密，离线可用、自动合并
  Self-hosted sync: PostgreSQL (real time), MySQL / MariaDB, Cloudflare D1 — end-to-end encrypted, works offline, merges automatically
