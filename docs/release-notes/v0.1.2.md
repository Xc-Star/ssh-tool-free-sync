本次更新新增应用内新版本检查：SSH Tool 会在启动后和每天自动检查一次 GitHub 上的新版本，发现新版时提醒你前往下载，不用再手动关注 Release 页面。

This release adds in-app update checks: SSH Tool now looks for new releases on GitHub shortly after startup and once a day, and lets you know when a newer version is available — no need to watch the releases page manually.

### 更新内容 · What's new

- **新增新版本检查提醒**：启动后和每天自动检查一次 GitHub Releases；发现新版本时在右下角弹出提醒，点击「前往下载」即可打开浏览器进入下载页面。GitHub API 因共享网络 IP 被限流（403）时，会自动改用备用通道继续完成检查，不受影响。
  **Update notifications**: SSH Tool checks GitHub Releases shortly after startup and once a day. When a newer version is released, a notification appears with a one-click link to the download page. If the GitHub API is rate-limited (403, common on shared network IPs), the check automatically falls back to an alternate channel.
- **新增手动检查与开关**：在「设置 → 关于」页可随时手动「检查更新」，发现新版本时显示当前版本与最新版本的对比横幅；自动检查可在「设置 → 通用」中关闭。
  **Manual check & controls**: "Check for updates" is always available in Settings → About, with a banner comparing your version against the latest. Automatic checks can be turned off in Settings → General.

### 首次运行 · First launch

- **Windows**：安装包未签名，SmartScreen 拦截时点击「更多信息 → 仍要运行」。
  The installer is unsigned: if SmartScreen blocks it, click **More info → Run anyway**.
- **macOS**：应用未经 Apple 公证，首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」。
  The app is not notarized by Apple: if macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux**：Ubuntu / Debian 推荐安装 deb；AppImage 需要 FUSE 2（Ubuntu 24.04：`sudo apt install libfuse2t64`）。
  On Ubuntu / Debian the `.deb` is recommended; the AppImage needs FUSE 2 (Ubuntu 24.04: `sudo apt install libfuse2t64`).
